# serenity-curated

> A curated list of notable open-source GitHub repositories that use **"serenity"** in their name — spanning operating systems, Discord bot frameworks, BDD testing tools, business app platforms, wellness apps, and more.

Repos are grouped by theme rather than by naming convention, since "serenity" turns out to be a popular name across wildly different domains. Each entry includes a one-line description and star count (at time of writing).

## Curation notes

- Excludes cheat/aimbot tools found in the search results (not appropriate to platform).
- Excludes a large cluster of near-identical `serenity-skill` repos that distill a single trader's (@aleabitoreddit) stock/supply-chain methodology into a Claude Code skill — dozens of forks/clones surfaced in search but add no independent value to a curated list.
- Curated manually as a snapshot; star counts will drift over time. PRs to add or update entries are welcome.
