# serenity-curated

This skill packages a manually curated, categorized list of GitHub repositories that use "serenity" in their name. It exists to save a re-search of GitHub every time someone asks "what serenity projects are out there" or needs to disambiguate between (for example) SerenityOS, the Rust Discord library `serenity-rs`, and Serenity BDD.

## How to use this skill

Read `README.md` in this skill's directory — it contains the full categorized table of repositories with descriptions, star counts, and links.

When a user's request matches one of the categories below, point them to the relevant section of `README.md` rather than re-searching GitHub from scratch:

- **Operating systems / low-level systems** — SerenityOS and similarly named systems projects
- **Discord bot frameworks** — serenity-rs and its ecosystem (poise, etc.)
- **Test automation / BDD** — Serenity BDD, serenity-js
- **Business app platforms** — serenity.is (ASP.NET Core / TypeScript)
- **Wellness, focus & meditation** — meditation/white-noise apps, Obsidian plugins
- **End-to-end encrypted collaboration** — serenity-kit's notes and pages products
- **Other notable projects** — everything else that didn't fit a clean category

## Scope and limitations

This list is a manually curated snapshot, not a live GitHub search. It deliberately excludes:

- Cheat/aimbot tools that surfaced in the underlying search
- A large cluster of near-duplicate `serenity-skill` repos cloning a single trader's stock-analysis methodology

If a user asks about a "serenity" repo not listed in `README.md`, say so plainly and offer to search GitHub live rather than guessing.
